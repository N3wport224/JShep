# Production SOP — Templates, Checklists & Tool Stack

*The system that makes video 40 as good as video 4, on autopilot. Everything here is the reusable version of what Phases 3–8 did once.*

## 1. The Script Skeleton (validated structure — start every long-form here)

```
COLD OPEN (0:00–0:35)
  [ ] Scenario or dare that puts the VIEWER inside the claim (no intro, no plug)
  [ ] Title claim restated HARDER by 0:15
  [ ] "Today we're opening it up" + schematic motif by 0:35
ACT 1 — THE MECHANISM (0:35–3:00)
  [ ] Concession beat ≤ 8s ("this isn't a scam / not a cabal")
  [ ] Core mechanism with ONE physical metaphor
  [ ] The shock stat at ~1:45 with silence + zoom-punch
ACT 2 — THE DEEPER GEAR (3:00–5:30)
  [ ] The counterintuitive thesis line on black at ~3:40 (slowest read)
  [ ] The profit/incentive answer ("who benefits & how")
ACT 3 — THE STORY (5:30–8:00)  ← retention trough defense
  [ ] One real, named, dated narrative; pace up 10%; music family Pulse
  [ ] Belief/system flaw revealed THROUGH the story, not before it
ACT 4 — WHAT YOU DO WITH THIS (8:00–9:45)
  [ ] Tonal reset ("Should you worry? Mostly, no.") + exactly 3 takeaways
CLOSE (9:45–10:30)
  [ ] "It isn't hidden" reflection beat → sequel loop opened → "No hype. Just the gears."
GLOBAL: ≥2 loops open at all times · spine loop closes ~70% · re-engagement beat every ≤90s ·
one concept/minute · concrete image between any two abstractions · hedge words kept in
```

## 2. Fact-Check Protocol (finance = one bad claim kills the channel)
1. Every number in the script gets a bracketed source in the draft: `[src: federalreserve.gov/...]`.
2. **Primary sources only** for claims: regulators, central banks, BLS/BEA, court filings, company filings. News articles are leads, not sources.
3. The three most disputable claims get on-screen citations AND go in the pinned comment.
4. Read the script asking: *"What would a hostile CPA comment?"* Fix or pre-concede every hit (the "prudence, not law" pattern).
5. Superlatives audit: every "most/never/only/first" must be verifiable or softened to "one of the."
6. Nothing is advice: no tickers, no "you should buy/sell," education disclaimer in every description.

## 3. Pre-Upload QC Checklist (run every time, ~15 min)
```
PACKAGING   [ ] Thumbnail readable at 120px  [ ] ≤3 words  [ ] Doesn't repeat title
            [ ] Title <60 chars  [ ] Claim survives the click (no betrayal)
OPEN        [ ] First visual change ≤4s  [ ] Interrupt ≤15s  [ ] No jargon before 3:00
AUDIO       [ ] VO −16 LUFS  [ ] Music ducked −12dB  [ ] The one silence beat intact
CAPTIONS    [ ] Burned dynamic captions synced  [ ] Full CC file uploaded
META        [ ] Description template filled  [ ] Chapters at loop boundaries
            [ ] End screen = 1 next video + subscribe  [ ] Pinned comment drafted
LEGAL       [ ] Stock licenses logged  [ ] No network chyrons  [ ] Archival is PD/licensed
            [ ] Disclaimer present  [ ] On-screen sources for top-3 claims
SERIES      [ ] Sequel loop opened  [ ] Master schematic updated with this video's machine
```

## 4. Tool Stack (solo, lean — upgrade only when a tool is the bottleneck)
| Job | Pick | Notes |
|---|---|---|
| Scripting | Google Docs + skeleton template | Comments = fact-check trail |
| VO recording | Audacity/Reaper + SM7B-class dynamic mic | Dynamic mic forgives untreated rooms |
| Edit | DaVinci Resolve (free tier is enough) | Build the motif library as a Power Bin |
| Motion graphics | After Effects or Resolve Fusion; motif templates reused | The schematic system amortizes the cost |
| Stock | Storyblocks (flat-rate) + Pexels/Pixabay (free) + Internet Archive/Prelinger (PD archival) | Log every clip + license in the tracker |
| Music/SFX | Epidemic Sound or Artlist (one subscription, 3 cue families) | Same artists per family = brand sound |
| Thumbnails | Photoshop/Figma; 3 candidates per video | Test at 120px before choosing |
| Analytics | YT Studio + weekly Phase-10 ritual | No paid tools until 10K subs |

## 5. Asset Library (grows every video — this is the moat)
`/assets/motifs/` master schematic (+ per-video machines) · lungs · dial · toll booth · ledger/IOU · counters/ratchets
`/assets/audio/` 3 cue families · ratchet-click · vault-thunk · audio-logo wind-down
`/assets/templates/` thumbnail PSD (grammar locked) · caption style · end screen · description/tags
**Rule:** every new video must reuse ≥ 3 library assets and may add ≤ 3 new ones. Reuse is the brand.

## 6. Weekly Operating Rhythm (pairs with Phase 9 batching)
- **Mon:** research/scripting block (no editing on writing days)
- **Wed:** VO day (batch everything recordable)
- **Thu–Fri:** edit block
- **Fri PM (30 min):** Phase-10 analytics ritual → log ONE binding constraint → pick next week's single fix
- **Always:** ≥1 finished video in the buffer; buffer empty = skip a Shorts day, never a Tuesday

## 7. Definition of Done (a video ships when…)
Script passed fact-check → VO recorded to spec → edit passes QC checklist → 3 thumbnails made, 1 chosen at 120px → metadata pack filled → scheduled for Tuesday 12:00 ET → pinned comment queued → Shorts clips marked in the timeline for recut. Anything less: it waits a week. The machine never ships late *and* never ships early-rough.
