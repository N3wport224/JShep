## 5. First-Month Operating Rules
- [ ] Tuesday slot is sacred; buffer ≥1 video before publishing anything (Video 2 script is ready in `12-…md` — batch it during Video 1's edit week)
- [ ] Friday 30-min analytics ritual from week 1, even with tiny numbers — the *habit* is the deliverable; log in `10-performance-analysis.md` changelog
- [ ] 48h after each publish: CTR check → thumbnail swap rule (≥4% = hold, <4% = swap to concept B)
- [ ] Touch nothing else: no logo redesigns, no cadence changes, no new formats for 8 weeks. The machine gets judged on 8 data points minimum.

## Pre-Registered Success/Kill Criteria (decide now, while calm)
- **8 weeks / 8 longs in:** if median CTR ≥ 4% and 0:30 retention ≥ 60% on any two videos → the format works; keep feeding it.
- If packaging metrics are healthy but views are flat → topic problem; re-weight toward Phase 2's top-10 list.
- If CTR is healthy but retention dies mid-video → production problem; fix pacing per Phase 10 tree before changing topics.
- **Nothing is a verdict before 8 published long-forms.** New-channel data is noise until then; the only failure mode in month 1–2 is missing Tuesdays.
